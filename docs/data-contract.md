# 到访材料含义

匿名person只在本产品的约定范围内标识同一参与者，不使用真实姓名。visit_id是一次到访事件；同一人同日到两馆有两次到访，但总人数仍是一个人。材料声明的学校、日期和场馆范围不是互斥分区。

团队材料的总人数代表其覆盖范围中的不同参与者，覆盖多馆不等于在每馆都到齐。团队与个体材料之间的包含关系只能根据报送方明确声明建立，没有声明的匿名明细不能自行推断为某团队成员。总人数与已解释覆盖矛盾时需要报告材料冲突。完整人数、当前可识别人数与尚不能按维度分配的余量是不同信息。

来源可更正一份材料或撤回其覆盖声明，但不会改变已经发出的月度摘录。现有明细接入只接受个体到访，团队级输入属于不同事实粒度。
